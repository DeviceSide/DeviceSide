# DeviceSide 0.2.0

Flash-free Home Assistant scenes, more lights with Labs off, and a view of what runs on your devices.

## Highlights

- **Flash-free scenes:** `set_scene` now takes your Home Assistant scenes, setting each light without turning it
  on, on every integration with flash-free turn-on.
- **Support for more light brands:** standard lights on Zigbee2MQTT, and other brands' lights on a Hue bridge, get
  smooth dimming, flash-free turn-on and scenes with Labs off.
- **See what works:** view which features run on each of your own lights and switches, in
  Configure > Settings.

## Fixes

- Zigbee2MQTT: custom base topics, and several instances on one broker, now work.
- Zigbee2MQTT: Hue and Aqara lights now dim to their lowest level (brightness = 1), bypassing Zigbee2MQTT's floor of
  brightness = 2.

## In Labs

Turn on Labs in Configure > Settings to try:

- **Matter lights:** smooth dimming, smooth color and flash-free turn-on.
- **Zigbee2MQTT timed on/off:** Tuya countdown timers, and auto-off on Sonoff relays and Tuya inching switches.
- **Shelly LED controllers:** color and color temperature on flash-free turn-on.

Models and how each was tested: the
[compatibility page](https://github.com/DeviceSide/DeviceSide/blob/main/docs/device-compatibility.md).
