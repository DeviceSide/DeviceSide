# DeviceSide 0.2.0

Flash-free Home Assistant scenes, more lights with Labs off, and a view of what runs on your devices.

## Highlights

- **More light brands supported:** standard lights on Zigbee2MQTT, and other brands' lights on a Hue bridge, get
  smooth dimming, flash-free turn-on and scenes.
- **Flash-free scenes:** `set_scene` now takes Home Assistant scenes, so you can set scenes before turning on the
  lights.
- **See what works:** DeviceSide shows you which features it supports on each of your own lights and switches, in
  Configure > Settings.

## Other improvements

- Zigbee2MQTT base topics: custom base topics and multiple Zigbee2MQTT instances on one broker are now supported.
- Hue and Aqara lights: now dim to their lowest level (brightness = 1) on Zigbee2MQTT, bypassing its blanket floor of
  brightness = 2.

## In Labs

Turn on Labs in Configure > Settings to try:

- **Matter lights:** smooth dimming, smooth color and flash-free turn-on.
- **Zigbee2MQTT timed on/off:** Tuya countdown timers, and auto-off on Sonoff relays and Tuya inching switches.
- **Shelly LED controllers:** color and color temperature on flash-free turn-on.

Models and how each was tested: the
[compatibility page](https://github.com/DeviceSide/DeviceSide/blob/v0.2.0/docs/device-compatibility.md).
