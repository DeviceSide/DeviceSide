Icons for the README feature table, from [Material Design Icons](https://pictogrammers.com/library/mdi/) (`@mdi/svg` 7.4.47, [Pictogrammers Free License](https://github.com/Templarian/MaterialDesign/blob/master/LICENSE)): `light` is `mdi:lightbulb`, `switch` `mdi:toggle-switch-variant`, `group` `mdi:lightbulb-group`, `scene` `mdi:palette`, filled amber (`#ffc107`, Home Assistant's color for an entity that is on). Each has a `-grey` twin (`#8a8a8a`) for what works only with the Experimental features option on. `devices` is `mdi:devices` in the same amber and `devices-grey` in the same grey, used only in the legend for released and experimental items. `no.svg` is a plain grey prohibited sign, one per cell for whatever can't be done there.
